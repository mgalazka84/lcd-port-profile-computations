# LCD and PORT profile computations

Reproducible finite-size comparisons of the attachment-weight profile of
the root component in the one-edge LCD model and the profile of a
plane-oriented recursive tree (PORT). LCD size `n` is paired with PORT
size `n + 1` throughout.

The code computes exact-formula mean differences, evaluates leading and
corrected approximations, and simulates an exact common coupling.
The numerical summaries are synthetic; no empirical network data are used.

## Reproduce

Requirements: Python 3.12, a C++17 compiler named `g++`, and the packages in
`requirements.txt`. The recorded run used GCC 13.3.0. The compiler builds
the simulator in a temporary directory, leaving no binary in this repository.

```sh
python -m pip install -r requirements.txt
python run_experiments.py
python validate.py
```

The default experiment generates 32,768 independent paths to LCD size
100,000, with checkpoints at 100, 1,000, 10,000 and 100,000. Seed 20261016
is fixed in the command-line defaults. Replicate `i` uses seed
`20261016 + i`. The integer stream is generated by `std::mt19937_64` and
explicit rejection sampling for a uniform bounded integer, rather than a
library-specific integer distribution. Floating-point rounding may differ
slightly across platforms.

To regenerate tables and figures from the supplied simulation:

```sh
python run_experiments.py --reuse-simulation
```

To run a smaller exploratory experiment:

```sh
python run_experiments.py --replicates 1024 --seed 12345
python validate.py
```

This replaces files in `results/`. Keep a copy if the reference results
are needed. `--reuse-simulation` checks the seed and replicate count
against `results/metadata.json` before using the stored simulation.

## Meaning of the numerical bounds

All Wasserstein distances here have **order one**. The parameter `p`
selects the ground norm; it is not the Wasserstein order. Coordinates
are normalized by `2^h h! / (sqrt(n) (log n)^h)` and norms are unaveraged.

Let `G = Y-X` be the nonnegative discrepancy under the coupling, and let
`mu = E[G]`, evaluated from the exact mean formulas. Then

```
norm(mu,p) <= Wasserstein distance <= E[norm(G,p)].
```

For `p=1` these bounds coincide exactly. For `p=2` and `p=infinity`, the
simulation estimates the cost of this coupling, not the optimal transport
distance. A supporting vector `q` satisfies `q.dot(mu)=norm(mu,p)` and
`q.dot(g)<=norm(g,p)`. We estimate the upper endpoint as

```
norm(mu,p) + sample_mean(norm(G,p) - q.dot(G)).
```

For `p=2`, `q=mu/norm(mu,2)`; for `p=infinity`, `q` selects a coordinate
with maximum mean gap. The residual is nonnegative. Its standard error
is usually much smaller than that of the raw coupling cost. Error bars
in the figures are pointwise `+/- 1.96` estimated standard errors, not
certified bounds on the optimal distance. Checkpoints on the same path
are dependent; standard errors are computed over independent paths.

## Files

- `profiles.py`: exact-formula means via Newton identities, transport
  lower bounds, leading and corrected sum-cost approximations.
- `simulate.cpp`: exact insertion-position simulation, raw and residual
  Monte Carlo means and standard errors, pathwise consistency checks.
- `run_experiments.py`: complete experiment and vector-figure generation.
- `validate.py`: independent direct mean recurrence and exact rational
  enumeration of parent-labelled PORT trees through seven vertices.
- `results/exact_l1.csv`: all `n=10^2,...,10^7`, `H=1,...,12`.
- `results/control_means.csv`: deterministic mean gaps used in the
  supporting functionals.
- `results/coupling_mc.csv`: raw costs and nonnegative residual summaries.
- `results/factor_samples.csv`: integer root weights at size 100,000;
  generated locally during simulation, not tracked.
- `results/joint_factor_histogram.csv`: supplied cell counts on the fixed
  grid used in the joint-density plot; includes no rescaling for truncation.
- `results/relative_factor_quantiles.csv`: the empirical and limiting quantiles.
- `results/transport_bounds.csv`: deterministic lower bounds, estimated
  coupling upper bounds, their standard errors and leading approximations.
- `results/logarithmic_window_diagnostic.csv`: exploratory maximum-cost
  calculation at `H=floor(0.35 log n)`; not a proof beyond an analytic domain.
- `results/metadata.json`, `results/validation.json`: provenance and checks.
- `results/Table_exact.tex`: regenerated numerical table.
- `results/Fig2.pdf`, `results/Fig3.pdf`, `results/Fig4.pdf`: figures generated
  locally by the script (not tracked); PNG previews are also generated.

Newton identities take O(H^2) arithmetic after the power sums have been
computed using digamma and Hurwitz-zeta functions. They are used only at
the modest degrees in the supplied experiments; this implementation is
not a validated interval-arithmetic algorithm for arbitrarily large H.
Simulation takes O(n) time and memory per path and processes paths
sequentially.

The first correction is asymptotic for H=o(log n). Its numerical use
outside that range is an approximation assessment, not an error guarantee.
